Шланги для харчової промисловості

Шланги для харчових продуктів виготовлені з матеріалів, дозволених для контакту з їжею: білих гумових сумішей без запаху та смаку, ПВХ, поліетилену та інших полімерів з високим ступенем чистоти. Вони не погіршують здоров'я та органолептичні властивості продуктів і використовуються також у фармацевтичній та косметичній промисловості.

Гігієна та стандарти

  • Матеріали для контакту з їжеюВнутрішній шар без шкідливих речовин, що не впливає на смак і запах продукту.
  • Регуляції ЄС1935/2004/EC (FCM) для всіх харчових шлангів, 2023/2006/EC (GMP), 10/2011/EU для шлангів з пластику.
  • Міжнародні стандартиFDA 21 CFR, NSF-51, 3-A Sanitary Standards, BfR.
  • Питна водаДиректива 98/83/ЄС, PZH, KTW, DVGW W270, WRAS, NSF-61.
  • Фармацевтика та медицинаUSP Class VI, ISO 10993.

Як підібрати шланг

Не кожен харчовий шланг підходить для всіх типів їжі. Використання шлангу має відповідати сертифікату або призначенню, рекомендованому виробником (наприклад, шланг для молока; шланг для вина, пива та фруктових соків; шланг для олій та жирів).
