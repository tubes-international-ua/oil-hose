Як це працює

Установка нижнього перевантаження — дві незалежні частини

Роз'єми API поділяються на з'єднання для рідин і з'єднання для випарів. Обидві магістралі працюють одночасно: продукт іде в цистерну, витіснені випари — назад у систему рекуперації.

Рідке паливо

Магістраль продукту

На автоцистерні стоїть втикова частина API (частина на баку), до неї підключається рукав із гніздом API («мамкою»). Гніздо та втикова частина мають поршневі клапани: відкрити їх можна лише після стикування, поворотом важеля на гнізді. Це і є сухороз'ємне з'єднання.

Втикову частину на цистерні можна відкрити й окремо — додатковим важелем, без під'єднання гнізда.

Розмір: єдиний 4" API, фланець 4" TTMA · Витрата: 2271 л/хв · Падіння тиску: 0,27 бар
Випари

Магістраль рекуперації

На бачку встановлена втикова частина із затвором, до якої підключається шланг зі спеціальними закінченнями для випарів. Гніздо обладнане клапаном, що відкриває прохід після з'єднання.

Комплект доповнюють дихальні клапани ADR і Mushroom, пневматичні клапани виведення випарів із магістралі рекуперації та оптичні чи електронні датчики переливу.

З'єднання: фланець 4" TTMA / CAMLOCK 4", фланці DN80 і DN100 · Ущільнення: Viton, NBR
Замість сухороз'ємного з'єднання можна підключити звичайний CAMLOCK. Для цього на роз'єм API-цистерни попередньо ставиться гравітаційний з'єднувач. Рішення дешевше й простіше, але воно вже не працює як сухороз'ємне — пролив при роз'єднанні буде.
